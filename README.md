**將軍澳培智學校**｜誠信價值觀學習週 × 數學科

## 三個學習模式（封面揀）

封面三張卡 → 揀 mode → **中學 mode 自動先經課堂引入** → 入地圖。
流程骨三個 mode 一致，分別喺「要攞咩」「咩叫跟單」同「有冇掃描／拍卡」。

| Mode | 標籤 | 學乜 | 清單格式 | 籃上限 | 掃描／拍卡 |
|---|---|---|---|---|---|
| **小學** | 🚪 小學·配對 | 圖片配對 · 誠實付款 | `items: [{id,qty}]` + `pic` flag（`"list"` 相片／`"name"` 名+數量） | 6 | ✅ |
| **中學·數** | 🔢 中學·數 | 數數 · 數字配對 | `items: [{id,qty},…]`（每樣要幾多件） | 6 | ✅ |
| **中學·形** | ▲●■ 中學·形 | 跟形 · 唔好手多多 | `shapes: [{shape,qty},…]`（每種形狀要幾多件） | 9 | ✅ |

### 小學·配對（圖片配對 · 2026-11-11）
清單卡分三級，**呈現方向唔同**：

| 卡 | 清單（門口卡 / 地圖清單條 / 核對枱三處一致） | 貨架 | 任務 |
|---|---|---|---|
| **初** | 曲奇**相片** | 🍪 曲奇 emoji | 相 → 實物 |
| **中** | 朱古力**相片** + 牛奶**相片** | 🍫 🥛 emoji | 相 → 實物 |
| **高** | 曲奇×2 + 飯糰（**名 + 數量**） | 真實**相片** | 名 → 相（相反方向） |

⚠️ **三處呈現必須一致** —— 門口卡、地圖清單常駐條、核對枱清單欄，任何一處唔同就會「清單常駐」紅線失守。
⚠️ **高卡嘅清單用名 + 數量** → 學生要按名搵相片，而且要攞 **2 件**（同一款 2 件要分開 2 個架位）。
⚠️ **c2（曲奇罐）唔入小學清單** —— c1／c2 嘅 emoji 都係 🍪，配對會有歧義。
⚠️ **小學唔顯示形狀 badge** —— badge 會令任務變成「搵形狀」，而且形狀對小學要求冇作用（會提前洩漏答案）。
⚠️ **小學用小學名**（`ITEMS[].sname`：曲奇／布甸／紙巾／朱古力／豆腐…），唔用「正方形紙巾盒」呢類中學名。

### 課堂引入（mode-aware）
`#s-intro` 畫面，每條問題有 🔊 TTS 同「睇答案」掣（答案預先收埋，唔會洩漏）。

**小學（4 條 + 順序配對）**

| # | 問題 |
|---|---|
| 1 | 圖片入面，有冇售貨員？ |
| 2 | 小朋友點樣買嘢？（**順序圖卡配對** ↓） |
| 3 | 冇售貨員，可以直接將零食放落書包走掉嗎？ |
| 4 | 我哋要先做咩動作才可以拿走？要「嘟卡」定係直接拿走？ |

**順序圖卡配對小任務**：3 張卡（①拿商品 🛒 ②掃描 📷 ③拍卡 💳）撳入次序槽。
- 答啱 → 「✓ 啱晒！先拿商品 → 再掃描 → 最後拍卡。」
- 答錯 → 「次序未啱。正確次序係 ①拿商品 → ②掃描 → ③拍卡。再試吓。」+ 清空重試
- ⚠️ **純練習**：唔影響星星、唔影響誠信判斷

**中學（3 條）**

| # | 問題 | 答案重點 |
|---|---|---|
| 1 | 圖片入面，有冇售貨員？ | 冇售貨員，一個人都冇 |
| 2 | 冇售貨員，我哋要自己做咩？ | 自己掃描商品 + 自己拍卡付錢 |
| 3 | 攞咗嘢，可以直接放落書包走人嗎？ | 唔可以。要先拍卡付錢，確認咗先可以攞走。 |


### 中學·數（數字配對）
清單寫「蘋果 ×3、牛奶 ×2、餅乾 ×5」。㩒貨架 → 彈出數字掣面板（1–10）→ 揀要攞幾多件 → 入籃。  
貨架上嘅嘢**唔寫數字**（特教學生要自己數），數字只喺清單同掣面板出現。  
掣面板**答錯唔懲罰**，只提示「再數一次，數吓有幾多件。」可以再試（呢關係練習，唔係評核）。

### 中學·形（形狀購物）
清單寫「●×2 ▲×1 ▬×1」—— **只講形狀同數量，唔講係咩貨**。  
貨架擺嘅係超市真貨圖（曲奇罐、蛋糕盒、紙巾盒、果汁盒…），每件貨右上角有形狀 badge（●▲■▬）。
學生要自己認形狀、自己數件數，睇到啱形先攞。

⚠️ **長方形（▬）入咗清單，正方形（■）改做干擾**（2026-11-10 改）。
中學課程要求 3 指定「圓形、三角形及**長方形**」，所以長方形一定要入單；
而正方形對長方形正正係中度學生最易混淆嗰位 —— 用佢做干擾，逼學生真係分辨形狀，唔係靠印象。

⚠️ **貨架難度已下調（2026-11-11）**：舊版架上同一形狀擺咗 2–3 款（高卡：正方形 3 款、三角形 2 款），
學生要逐款比較先知邊件啱，仲好容易「多取」→ 跟單失敗。
而家 **每種清單要嘅形狀，架上只擺清單需要嗰啲件數**，其餘架位用 **不規則物件**
（香蕉／茄子／粟米／西蘭花／魚／襪子，emoji + 白底框，冇相片）填 ——
每種目標形狀喺架上唯一可辨，學生唔會揀錯形狀。
判分 **唔放寬**：攞咗不規則干擾物 = 多取 = 跟單失敗（冇星），「忍住手唔好多取」呢個教學點原封不動。

| 卡 | 清單 | 貨架供應（9 位） | 重點 |
|---|---|---|---|
| **中** | ●2 ▲1 ▬1 | ●2 ▲1 ▬1 ＋ ■1 ＋ 不規則 ×4 | 只比一次「■ vs ▬」；多一個正方形干擾要忍住手 |
| **高** | ●2 ▲1 ■1 ▬1 | ●2 ▲1 ■1 ▬1 ＋ 不規則 ×4 | 每種形狀喺架上唯一可辨，唔會揀錯 |

### 掃描 + 拍卡（三個 mode，要求 4／5）
| 畫面 | 做乜 |
|---|---|
| **掃描商品** `s-scan` | 逐件 📷 掃描；每件顯示單價 × 件數；頂部累計「應付 $X」；底部兩欄並排 **清單要** vs **我掃咗**（只列數量，**唔話啱錯**） |
| **拍卡** 櫃檯 | 顯示應付金額 + 電子錢包（八達通卡卡面）；掣改成「拍卡付足錢 / 只畀一半錢 / 唔付款就走」（小學用「嘟卡」語言） |
| **收據** | 付款完成 $X（拍卡成功·全部付清）／仲未付足（仲差 $X）／冇付款；學生要撳「好，睇結果」先入結果畫面 |

⚠️ **掃描畫面唔會話啱／錯** —— 對錯留到結果畫面先講（教學紅線：系統唔提前洩漏對錯）。
⚠️ **金額只係讀，唔使心算** —— 逐件顯示單價、頂部自動加總，唔引入「數銀」（數銀 = 自由地圖，永不做的功能）。
⚠️ **掃描要掃齊先可以去拍卡**；漏掃唔會變成誠信選項（誠信判斷留喺櫃檯嗰步）。

### 放返低（要求 4：數錯要有得救）
籃入面每件貨右下角有 **↩** 掣 → 撳會放返上架（貨架嗰格返晒原位）。
⚠️ **只限地圖畫面（未做逐項核對之前）** —— 核對之後再改籃，會令「逐項核對」記錄同實際唔一致。
冇呢個功能嘅話：學生數錯一件 → 冇得救 → 成張單直接失敗，中度學生會撞牆（而唔係學到嘢）。

**銀／金雙星**（只有呢個 mode 有雙星）
| | 條件 | 意思 |
|---|---|---|
| 🥈 **銀** | 跟單（形狀 + 數量全部啱） | 忍住手，冇多攞 |
| ⭐ **金** | 跟單 **+** 櫃檯比足錢 | 誠信兩樣都做到 |

⚠️ **形錯 ≠ 不誠實**。形狀／數量錯淨係代表「下次要對清楚」，**唔會**判學生唔誠信。
付咗足錢但形狀唔啱 → 仍然講「你有付足」，只有「對貨答覆同實際唔一致」先係誠信落差（老師記錄會標）。

## 已知 bug 同陷阱

### v1 有、v1.5 修嘅版面 bug

1. **地圖被壓扁** — `.screen` 係 column flex，`#mapStage` 預設 `flex-shrink:1`，
   內容一超高度，`aspect-ratio` 就失效，地磚被拉成扁平條。修：`flex:0 0 auto`
   + 闊度上限改用 `min(560px, 92vw, calc(min(46vh,420px) * 1.2222))`，
   令高度被夾時闊度跟住縮，格仔維持正方形。
2. **清單被捲出畫面** — 矮視窗（筆電／分屏）會令頂部「清單」離開畫面，
   踩咗「清單常駐」紅線。修：`@media (max-height:820px)` 壓細方向掣。

### v1.6 修嘅 crash：形狀 mode 100% 死機

**症狀**：揀「中學·形」入地圖 → `TypeError: Cannot read properties of undefined (reading 'name')`
（`index.html` `updateHotspots` → `renderMap` → `startList`）。即係**一入形狀 mode 就死**。

**根因**：`listIds(list)` 喺形狀 mode 回傳嘅係**形狀名**（`["circle","triangle","square"]`），
唔係 item id。但 `renderMap()` 照攞 `listIds(L).concat(shelfIds(L))` 當 id 用 →
`"circle"` 被塞入 `shelfItems` → `ITEMS["circle"]` → `undefined` → `ITEMS[id].name` 讀唔到。

**修**：
```js
// 形狀 mode 全部實物都喺貨架，清單只描述形狀 → 只擺 shelfIds()
const ids = isShapeMode() ? shelfIds(L) : listIds(L).concat(shelfIds(L));
```
另外加咗兩個防禦性 guard：
- `updateHotspots()` — 未知 id 用 `ITEMS[id] ? … : "貨架"`，唔會再令成個地圖死機
- `setMode()` — 補 `state.stars = 0; state.log = [];`（切 mode 等於開新一節，唔應該帶住上一個 mode 嘅星星／記錄）

⚠️ **呢個係「唔好亂用 listIds()」嘅通用陷阱**：佢喺三個 mode 回傳三唔同語意嘅嘢
（形狀 mode = 形狀名 · 其他 = item id）。新增 mode 嗰陣，
`listIds()` 嘅每個 call site 都要重新睇。

### v1.9 期間捉到嘅 bug（全部已修）

1. **長方形入單後，跟單一定判錯** — `shapeMatchInfo()` 寫死「攞咗 rect 就當多取」，
   長方形正式入單之後，跟單啱都判成錯，派唔到金星。
   **修**：四種形狀統一比較（只有「攞多咗」先算多取）。
   ⚠️ 呢類 bug **code review 睇唔出** —— 改資料層（清單加長方形）嗰陣唔會同步改
   判分層，結果係「資料啱、判分錯」。**改清單格式 = 必查判分層**。

2. **`hidden` 屬性被 CSS `display:flex` 蓋過** — 收據彈唔出、掃描步驟唔收埋。
   **修**：全局加 `[hidden]{ display:none !important; }`。
   ⚠️ **HTML `hidden` 唔係萬能** —— 只要 CSS 寫咗 `display`，`hidden` 就會失效。

3. **引入「睇答案」撳落爆 TypeError** — 用 `parentElement` 搵答案層，搵錯層 → `null.hidden`。
   **修**：改用 `b.closest(".iq")`。

4. **深色封面睇唔到字** — `.week-route` 用 `var(--ink)`（深色）落喺深色封面；
   `.school-brand .sb-name/.sb-sub` 同一問題（由 `1da9864` 引入）。
   **修**：改用淺色變數。

5. **`--paper` CSS 變數從未定義** — 靠「啱巧」繼承到啱嘅值。已補 `--paper: #F4E4BC`。

6. **籃太高，頂部「清單常駐」條被切走** — 籃內每件貨掛 30px 形狀 badge，撐高 `#bottombar`，
   令清單條離開畫面 = **踩教學紅線**。
   **修**：籃內唔掛 badge（caption 已經有 ●2 ▲1 ▬1）、相縮細、`.items` 加 `max-height`。

7. **封面 mode 推介卡跌出畫面** — `.mode-pick` flex 摺成 2 行，推薦嘅「中學·形」卡唔見咗。
   **修**：改 grid 3 欄 + 窄屏壓細。

8. **地圖內容過高時頂部被切兼埋唔到** — `#s-map` 用 `justify-content:center`，
   內容一高過視窗，頂部「清單」條同埋唔到嘅地圖一齊出事。
   **修**：改用 auto-margin 技巧（`justify-content:flex-start` + `::before/::after{margin:auto}`）。

9. **落單後門口籃度殘留上一單嘅貨** — `nextList()` 跳門口畫面時籃未清，
   學生見到「籃度有 3 樣嘢」，而且「放返低」↩ 掣仲喺度但按落冇反應。
   **修**：`nextList()` 入面清 `basket`/`basketN`/`basketFrom` + `renderBasket()`。

### v2.0 期間捉到嘅 bug（全部已修）

1. **順序配對答錯嘅提示會即刻被洗走** — `renderOrderSlots()` 每次都會用
   「已排 N 張，仲有 M 張未排」覆蓋 `#orderHint`；答錯時先寫提示、再 `renderOrderSlots()`
   清空重試 → **錯誤提示喺同一個 tick 被覆蓋，學生永遠睇唔到「次序未啱」**。
   **修**：調換次序 —— 先 `renderOrderSlots()`，後寫提示 + 加 `bad` class。
   ⚠️ **同一個 render 函式同時做「重繪」同「寫提示」就一定有 race** ——
   提示一定要寫喺最後。

2. **同一款 2 件，一放就清晒 2 件** — `putBack()` 原本直接 `basket[id] = null`，
   高卡曲奇 ×2 放一次就由 2 件變 0 件，貨架亦只復位 1 格。
   **修**：新增 `state.basketSlots[id]`（記每件貨自己嘅架位），
   每次 `putBack()` 只減 1 件、放返去對應嗰格。

3. **清單呈現三處唔一致** — 門口卡用相片，但核對枱清單欄用 emoji，
   學生核對時搵唔到對應嘢。**修**：清單呈現統一由 `pic` flag 決定
   （`"list"` = 相片 / `"name"` = 名 + 數量），門口卡 / 地圖清單條 / 核對枱三處共用。
   ⚠️ **「清單常駐」唔止係「清單條唔准消失」，仲包括「清單喺每一處都要長一樣」**。
